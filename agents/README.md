# Empire Wheel contributor roles

These guides turn the workflow in the root `AGENTS.md` into explicit handoffs.
They describe responsibilities, not autonomous runtime agents. One contributor
may fill several roles, but must produce each role's artifacts and preserve the
historical-review boundary.

Use the roles in this order for curriculum delivery:

1. curriculum architect
2. research and media curators
3. historical reviewer
4. requirements writer
5. implementation

Unchecked research stays in `content/research/`. Checked source metadata belongs
in `content/sources/`. Only typed learner content that clears the publication
gates belongs under `content/spokes/`.
