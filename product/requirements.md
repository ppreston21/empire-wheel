# Empire Wheel v0.1 Requirements

## Home

Display an 18-spoke competency wheel.

Only Mesopotamia is active.

The remaining spokes should appear locked or inactive.

Display:
- overall progress
- Mesopotamia progress
- modules completed

## Mesopotamia Curriculum

Display 10 modules.

For v0.1 only Module 1 needs complete content.

Module 1:
Sumer and the First Cities

Sections:

1. Overview
2. Key concepts
3. Primary source
4. Source analysis exercise

## Source Exercise

Display:

- source title
- date
- location
- source type
- transliteration or source text
- translation
- historical context

Ask the user:

"What can this source tell us about the society that produced it?"

Provide a large response field.

User clicks:

Submit Analysis

## AI Reviewer

The AI reviewer must return:

- historical accuracy: 1–10
- evidence usage: 1–10
- reasoning: 1–10
- unsupported claims
- strongest observation
- suggested improvement

The AI should not simply provide the ideal answer before the user
attempts the exercise.

## Progress

After submitting an analysis:

mark the exercise complete.

Progress may initially be stored locally in the browser.

## Out of Scope

Do not implement:

- authentication
- payments
- social features
- leaderboards
- peer review
- expert review
- blockchain
- persistent user database
- mobile application
